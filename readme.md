# Taming of the Shrew Game

## Play the game

### Play
You can play the game [here](https://jboss-64.github.io/Taming-of-the-Shrew-Game/)

### Controls
Play by using WASD or the arrow keys, and space to advance through dialouge

You can enable debug mode by pressing L

## Creation
This game was created by me for a project on the Taming of the Shrew for my English Class

All of the sprites were made by me except for the title screen and the start button. The start button can be found [here](https://www.vecteezy.com/vector-art/9878335-pixel-art-metallic-style-start-button-vector-icon-for-8bit-game-on-white-background).
